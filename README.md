# The Weekly Ticket

A one-page weekly meal planner. Pick a breakfast, lunch, dinner and snack for each day of the week, and the page adds up the calories, protein and fiber for every day and for the whole week, colored against your daily calorie goal. Each meal comes with a short note on why it's good for you, and the **Grocery List** tab turns the week's picks into one shopping list grouped by store section, ready to copy or download.

**View the page:** https://angelaor.github.io/Weekly-Ticket/

Everything is in one `index.html` file with no build step, so it runs on GitHub Pages or any static host.

## Using the page

| Feature | What it does |
| --- | --- |
| **This Week** | Choose a meal for each slot from the dropdowns. Daily and weekly totals update as you go. |
| **Daily calorie goal** | Set your own target (1,200 to start). Days over the goal are flagged so you can adjust. |
| **+ Add your own meal** | Pick this from any dropdown and enter the meal's name, calories, protein, fiber and ingredients. Its ingredients go on the grocery list too. |
| **Reset week** | Clears every slot so you can plan a new week from scratch |
| **Grocery List** | Everything you need for the week, sorted by section (produce, dairy, meat, pantry, refrigerated). Press **Copy list as text** or **Download as .txt**. |
| **💬 Send feedback** | Opens a short form so anyone trying the page can say what was confusing, what they liked, or what's missing |

Your week is saved in your browser as you go: meal picks, custom meals, your calorie goal and the grocery check-offs all stay put when you refresh or come back later. They're saved on that device only, so your phone and laptop each keep their own week.

## Host it on GitHub Pages

In the repository, go to Settings → Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, and save. The page will be at https://angelaor.github.io/Weekly-Ticket/ a minute or two later.

## Feedback

Feedback from the **Send feedback** button is collected through Formspree, so there is no server to run. Submissions appear in the Formspree dashboard.

## A note on health

This planner supports healthy eating habits and general meal planning. It is not medical or nutritional advice. Please check with a doctor or registered dietitian before starting a calorie-restricted plan, especially if you have a health condition.
